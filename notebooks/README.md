# Bitcoin-Price-Prediction-ML
# 📈 Bitcoin Price Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on analyzing historical Bitcoin market data and building a Machine Learning model to predict Bitcoin prices. The project begins with Exploratory Data Analysis (EDA) to understand market trends and will later include data preprocessing, feature engineering, model training, evaluation, and prediction.

## 🎯 Objectives

- Analyze historical Bitcoin market data.
- Perform Exploratory Data Analysis (EDA).
- Visualize Bitcoin price trends and trading volume.
- Prepare the dataset for Machine Learning.
- Train and compare multiple ML models.
- Predict future Bitcoin prices.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
